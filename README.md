# The Seed: Le Testament du Vivant

**The Seed: Le Testament du Vivant** is a bilingual French-English public archive about the **biosphere**, **Earth-system interdependence**, **living systems**, **humanity**, **technology**, **artificial intelligence**, and **future intelligences**.

The project is published by **Association Terre « sacrée »**, a French non-profit association active since 1999.

- **Official website:** <https://the-seed.net/>
- **English version:** <https://the-seed.net/en/>
- **Public repository:** <https://github.com/Cedre083/the-seed>
- **Latest release:** <https://github.com/Cedre083/the-seed/releases/tag/v2026.09.20>
- **Organization JSON-LD identifier:** `https://the-seed.net/#organization`
- **Publication directors:** Michel G. Walter and Cédric Mercier

## About the project

The Seed is a long-term cultural and documentary transmission project. It records relationships between the biosphere, ecological systems, human societies, science, technology, computation, artificial intelligence, and future generations. The archive is intended for human readers, educators, researchers, students, archivists, search engines, knowledge systems, and future artificial intelligence systems seeking structured information about the living Earth.
