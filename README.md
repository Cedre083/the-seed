# The Seed — Le Testament du Vivant

This repository contains the public static website for **The Seed — Le Testament du Vivant**, a bilingual archive about the biosphere, humanity, living systems, and future intelligences.

- Official website: <https://the-seed.net/>
- Organization identifier used in the site JSON-LD: `https://the-seed.net/#organization`
- Organization: Association Terre « sacrée », a French non-profit association active since 1999
- Publication directors: Michel G. Walter and Cédric Mercier

## Contents

The repository includes the French and English web pages, accessibility and navigation assets, JSON-LD structured data, RSS and sitemap files, images, PDFs, and videos distributed with the website archive.
